# Newsroom training outline (90 minutes)

## Goals

Correspondents and editors can file Breaking, move Articles through review, and understand what they cannot do.

## Agenda

1. **Product promise** (10m) — youth-first campus information; not a streaming clone.
2. **Roles** (10m) — Correspondent vs Editor vs EIC; campus scope.
3. **Breaking Fast Lane** (20m) — submit → verify → publish; banner; timeline updates.
4. **Article workflow** (20m) — Draft → Review → Changes/Verification → Ready → Publish/Schedule.
5. **Sources** (10m) — private fields never public; when to escalate.
6. **Utility content** (10m) — Opportunities / Events create + publish.
7. **Drills** (10m) — each person submits a test Breaking; editor publishes.

## Handouts

- Dev/staging URLs
- Capability cheat sheet (cannot publish if JOURNALIST)
- Tip line: public `/tip`

## Sign-off

Trainee initials + date after completing a supervised Breaking publish cycle.

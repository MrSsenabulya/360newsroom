# Campus 360 — Visual References

The `visuals/` directory contains early Phase 8 visual studies.

These are **directional**, not production-ready UI specifications.

Use them to understand:
- the separation between Public, Newsroom and 360 Control;
- editorial rather than streaming-first hierarchy;
- stronger Programme identity;
- operational density in internal tools.

The authoritative visual rules are in `design-system.md`.
